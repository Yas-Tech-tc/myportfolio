## Project Description

This project is a **responsive personal portfolio website** that lets a visitor quickly discover who I am, my skills, my projects and how to contact me.

It was built as part of the WAMD module (TP 1) using only **HTML5, CSS3 and JavaScript**, with a modern dark design inspired by a "lavender night" color palette. The site works on **desktop, tablet and smartphone**.

---

##  Features

- **Sticky navigation bar** with a blurred glass effect
- **Mobile burger menu** (opens and closes with JavaScript)
- **Active link highlighting** in the navbar while scrolling
- **Smooth scrolling** between sections
- **Home** section with a presentation and call-to-action buttons
- **About** section with a short biography and education
- **Skills** section organized by category (Frontend, Backend, Databases, Tools) with technology icons
- **Projects** section where the cards are **generated dynamically with JavaScript** from a list of objects
- **Contact** section with direct links (GitHub, Email, LinkedIn, WhatsApp)
- **Responsive design** for desktop, tablet and smartphone using CSS Grid, Flexbox and media queries
- **Hover animations** on cards and buttons

```bash

# 3. Open index.html in your browser
```

No installation is needed: the project uses only static files.
